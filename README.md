# Miltalk Console

ESP32-S3 educational game console firmware for the Miltalk camera kit.

Activities: Mind Reader, Pet Trainer, Detective, Racer, and Camera Lab.

## Getting started

Download or clone this repository, then open
`Miltalk_Console_Adventure/Miltalk_Console_Adventure.ino` in Arduino IDE.
Keep all headers in that sketch folder.

See [the firmware setup guide](Miltalk_Console_Adventure/README.md) for board
settings, libraries, wiring, controls, and verification limitations.
